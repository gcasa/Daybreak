DBMachine : DBProcessor

insertFloppy: readOnly: 

- (void) insertFloppy: (NSString*)path readOnly: (BOOL)readOnly;
Insert IMD/DMK media. Replacement preserves a 500 ms door-open interval. Raises DBFloppyError if changed media would be discarded; export or eject explicitly first. Loading failure leaves the old medium in place.

- (void) setHostID: (NSString*)identifier;
Set a six-byte unicast Ethernet ID before boot. Twelve hexadecimal digits, optionally separated by colons or hyphens; invalid IDs raise an exception. The default ID preserves the reference ViewPoint configuration.
